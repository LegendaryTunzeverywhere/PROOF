# 💻 Web Development - Complete Curriculum (25 Lessons)

**Duration**: ~26 hours | **Level**: Beginner → Intermediate
**Outcome**: Build production-ready websites and web applications

## Level 1: Absolute Beginner (8 lessons, 3.5 hours)
1. **What is HTML?** (20min) - First element, browser basics
2. **Document Structure** (20min) - DOCTYPE, html, head, body, meta tags
3. **Headings & Paragraphs** (20min) - h1-h6, p, strong, em
4. **Links & Navigation** (25min) - Anchor tags, URLs, navigation menus
5. **Images & Media** (25min) - img, alt text, formats, figure
6. **Lists** (20min) - ul, ol, dl, nesting lists
7. **Semantic HTML** (30min) - header, nav, main, article, footer
8. **Forms Basics** (30min) - form, input, label, button, validation

## Level 2: CSS & Responsive (8 lessons, 4 hours)
9. **CSS Syntax & Selectors** (25min) - Rules, classes, IDs, cascade
10. **Colors & Typography** (30min) - Fonts, sizes, colors, spacing
11. **The Box Model** (30min) - Content, padding, border, margin
12. **Display & Positioning** (30min) - Block, inline, flex, position
13. **Flexbox Layout** (35min) - Flex containers, alignment, gaps
14. **CSS Grid Layout** (35min) - Grid template, placement, responsive
15. **Responsive Design** (35min) - Mobile-first, media queries, fluid units
16. **CSS Variables** (30min) - Custom properties, design tokens

## Level 3: JavaScript & Interactivity (9 lessons, 5.5 hours)
17. **JavaScript Basics** (35min) - Variables, types, console
18. **Functions** (35min) - Declaration, parameters, returns, scope
19. **Conditionals & Logic** (30min) - if/else, operators, switches
20. **Arrays & Loops** (35min) - Collections, iteration, array methods
21. **DOM Selection** (30min) - querySelector, element references
22. **DOM Manipulation** (30min) - textContent, classList, attributes
23. **Events & Listeners** (35min) - addEventListener, event types
24. **Forms & Validation** (35min) - preventDefault, input values
25. **Fetch & APIs** (40min) - async/await, REST APIs, JSON

**Final Assessment**: Full landing page (90min, 10 NIM, 500 XP)
