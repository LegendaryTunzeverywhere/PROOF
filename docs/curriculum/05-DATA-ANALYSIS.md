# 📊 Data Analysis - Complete Curriculum (24 Lessons)

**Duration**: ~24 hours | **Level**: Beginner → Intermediate
**Outcome**: Analyze data, find insights, communicate findings

## Level 1: Data Fundamentals (8 lessons, 3.5 hours)
1. **What is Data Analysis?** (20min) - Process, roles, applications
2. **Data Types** (20min) - Nominal, ordinal, interval, ratio
3. **Spreadsheet Basics** (25min) - Cells, formulas, functions
4. **Data Cleaning** (30min) - Missing values, duplicates, errors
5. **Basic Statistics** (25min) - Mean, median, mode, standard deviation
6. **Data Validation** (25min) - Quality checks, business rules
7. **Filtering & Sorting** (20min) - Finding patterns, organizing data
8. **Basic Formulas** (30min) - SUM, AVERAGE, COUNT, IF

## Level 2: Analysis Techniques (8 lessons, 4 hours)
9. **Pivot Tables** (35min) - Grouping, aggregating, cross-tabs
10. **VLOOKUP & XLOOKUP** (30min) - Joining data, lookups
11. **Conditional Logic** (30min) - IF, AND, OR, nested conditions
12. **Date & Time** (25min) - Date arithmetic, formatting, functions
13. **Text Functions** (25min) - Parsing, cleaning, concatenating
14. **Percentages & Ratios** (30min) - Growth, conversion, composition
15. **Distributions** (35min) - Histograms, outliers, quartiles
16. **Correlation** (30min) - Relationships, scatter plots, causation

## Level 3: Visualization & Reporting (8 lessons, 4.5 hours)
17. **Chart Types** (30min) - Bar, line, pie, scatter, when to use
18. **Effective Visualizations** (35min) - Design principles, clarity
19. **Dashboards** (40min) - Layout, metrics, interactivity
20. **SQL Basics** (40min) - SELECT, WHERE, JOIN, GROUP BY
21. **Python for Data** (40min) - Pandas basics, data frames
22. **Statistical Tests** (35min) - T-tests, significance, p-values
23. **Data Storytelling** (35min) - Narrative, context, recommendations
24. **Presentation Skills** (40min) - Deck structure, speaking, Q&A

**Final Assessment**: Complete data analysis report (90min, 10 NIM, 500 XP)
