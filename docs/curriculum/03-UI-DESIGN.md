# 🎨 UI Design - Complete Curriculum (22 Lessons)

**Duration**: ~22 hours | **Level**: Beginner → Intermediate
**Outcome**: Design professional, user-friendly interfaces

## Level 1: Design Fundamentals (7 lessons, 3 hours)
1. **What is UI Design?** (20min) - Interface vs experience, good design
2. **Visual Hierarchy** (25min) - Size, color, spacing, contrast
3. **Alignment & Grid** (25min) - Grids, alignment, visual order
4. **White Space** (20min) - Breathing room, grouping, readability
5. **Contrast** (25min) - Figure-ground, emphasis, accessibility
6. **Balance** (20min) - Symmetry, asymmetry, visual weight
7. **Consistency** (30min) - Patterns, predictability, design systems

## Level 2: Typography & Color (8 lessons, 3.5 hours)
8. **Typography Basics** (25min) - Typeface anatomy, categories
9. **Font Selection** (30min) - Choosing fonts, pairing, hierarchy
10. **Type Scale** (25min) - Size relationships, modular scale
11. **Readability** (25min) - Line length, spacing, contrast
12. **Color Theory** (30min) - Hue, saturation, brightness, harmony
13. **Color Palettes** (30min) - Creating palettes, 60-30-10 rule
14. **Color Psychology** (25min) - Meaning, emotion, culture
15. **Accessibility** (30min) - WCAG, contrast ratios, color blindness

## Level 3: Components & Systems (7 lessons, 4 hours)
16. **Buttons & CTAs** (30min) - States, hierarchy, placement
17. **Forms & Inputs** (35min) - Labels, validation, error states
18. **Navigation** (35min) - Menus, breadcrumbs, tabs, patterns
19. **Cards & Lists** (30min) - Information architecture, scanning
20. **Icons & Imagery** (35min) - Icon systems, photography, illustration
21. **Responsive Design** (40min) - Breakpoints, mobile-first, patterns
22. **Design Systems** (40min) - Tokens, components, documentation

**Final Assessment**: Design a complete app interface (90min, 10 NIM, 500 XP)
