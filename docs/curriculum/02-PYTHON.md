# 🐍 Python - Complete Curriculum (24 Lessons)

**Duration**: ~24 hours | **Level**: Beginner → Intermediate
**Outcome**: Automate tasks, analyze data, build applications

## Level 1: Python Fundamentals (8 lessons, 3.5 hours)
1. **Python Basics** (20min) - Installing Python, running scripts, print()
2. **Variables & Types** (20min) - Strings, numbers, booleans, None
3. **String Operations** (25min) - Concatenation, f-strings, methods
4. **Numbers & Math** (25min) - Arithmetic, comparison, math module
5. **Input & Output** (20min) - input(), print formatting, file basics
6. **Booleans & Logic** (25min) - True/False, and/or/not, truthiness
7. **Comments & Style** (20min) - PEP 8, docstrings, naming conventions
8. **First Programs** (30min) - Calculator, greeter, simple games

## Level 2: Control Flow & Data (8 lessons, 4 hours)
9. **If Statements** (25min) - if/elif/else, nested conditions
10. **While Loops** (30min) - Loops, break, continue, infinite loops
11. **For Loops** (30min) - Iteration, range(), enumerate()
12. **Lists Basics** (30min) - Creating, accessing, slicing, mutating
13. **List Methods** (30min) - append, extend, pop, sort, reverse
14. **Tuples** (25min) - Immutable sequences, packing/unpacking
15. **Dictionaries** (35min) - Key-value pairs, accessing, methods
16. **Sets** (25min) - Unique values, operations, when to use

## Level 3: Functions & Modules (8 lessons, 4.5 hours)
17. **Function Basics** (30min) - def, parameters, return, docstrings
18. **Function Arguments** (35min) - Positional, keyword, default, *args, **kwargs
19. **Scope & Closures** (35min) - Local, global, nonlocal, closures
20. **Lambda Functions** (25min) - Anonymous functions, map, filter
21. **List Comprehensions** (35min) - Syntactic sugar for loops
22. **File Operations** (40min) - Reading, writing, context managers
23. **Error Handling** (35min) - try/except, raising errors, finally
24. **Modules & Imports** (35min) - import, from, creating modules, packages

**Final Assessment**: Data processor script (90min, 10 NIM, 500 XP)
