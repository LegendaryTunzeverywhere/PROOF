# 🤖 AI - Complete Curriculum (22 Lessons)

**Duration**: ~22 hours | **Level**: Beginner → Intermediate
**Outcome**: Use AI tools productively and build AI workflows

## Level 1: AI Fundamentals (7 lessons, 3 hours)
1. **What is AI?** (20min) - ML, LLMs, capabilities, limitations
2. **Prompt Basics** (25min) - Instructions, context, examples
3. **ChatGPT Essentials** (25min) - Interface, conversations, settings
4. **Effective Prompts** (30min) - Clarity, specificity, iteration
5. **AI for Writing** (25min) - Drafts, editing, brainstorming
6. **AI for Code** (25min) - Code generation, debugging, explanation
7. **AI Limitations** (25min) - Hallucinations, bias, when not to use

## Level 2: Advanced Prompting (8 lessons, 4 hours)
8. **Prompt Engineering** (30min) - Templates, variables, chaining
9. **Few-Shot Learning** (30min) - Examples, patterns, consistency
10. **Role Prompting** (25min) - Personas, expertise, tone
11. **Chain of Thought** (30min) - Step-by-step reasoning, complex tasks
12. **Prompt Templates** (35min) - Reusable patterns, placeholders
13. **AI for Research** (30min) - Summarization, synthesis, fact-checking
14. **AI for Analysis** (35min) - Data interpretation, insights
15. **Multimodal AI** (30min) - Image generation, vision, audio

## Level 3: AI Workflows & Integration (7 lessons, 4 hours)
16. **Workflow Automation** (35min) - Zapier, Make, n8n with AI
17. **AI APIs** (40min) - OpenAI API, authentication, requests
18. **Custom GPTs** (35min) - Instructions, knowledge, actions
19. **RAG Systems** (40min) - Retrieval, embeddings, context
20. **AI for Business** (35min) - Use cases, ROI, implementation
21. **Ethics & Safety** (35min) - Bias, privacy, responsible use
22. **Future of AI** (30min) - Trends, agents, what's next

**Final Assessment**: Build an AI-powered tool (90min, 10 NIM, 500 XP)
